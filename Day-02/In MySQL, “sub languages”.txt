
SQL stands for Structured Query Language.

It is a language used to communicate with a database. We use SQL to create, store, retrieve, update, and delete data in a database.

Simple daily-life example

Think of a school database:

Add a new student → INSERT
See student details → SELECT
Change student's phone number → UPDATE
Remove a student → DELETE

Example:

SELECT * FROM students;

This means: “Show me all the students.”


SQL is a standard language used to communicate with and manage data in relational databases.


Features of SQL:

The main features of SQL (Structured Query Language) are:

Easy to learn – SQL uses simple English-like commands.
Data retrieval – We can easily get required data using SELECT.
Data manipulation – We can add, modify, and delete data using INSERT, UPDATE, and DELETE.
Database creation – We can create databases and tables using CREATE.
Data security – SQL can control who can access or modify data.
Data integrity – SQL helps maintain accurate and consistent data.
Transaction management – SQL supports COMMIT and ROLLBACK to manage transactions.
Works with large data – SQL can handle and search large amounts of data efficiently.
Relationship between tables – SQL supports relationships using keys and JOIN.
Widely supported – SQL is used with databases such as MySQL, Oracle, SQL Server, and PostgreSQL.



# Sub Languages:

In MySQL, “sub languages” usually means the sub-languages of SQL. SQL is divided into different categories based on what we use it for.

1. DDL – Data Definition Language

Used to create or change the structure of a database.

Commands:

CREATE
ALTER
DROP
TRUNCATE

Example:

CREATE TABLE students (
    id INT,
    name VARCHAR(50)
);
2. DML – Data Manipulation Language

Used to add, change, or remove data.

Commands:

INSERT
UPDATE
DELETE

Example:

INSERT INTO students VALUES (1, 'Vikas');
3. DQL – Data Query Language

Used to retrieve data.

Command:

SELECT

Example:

SELECT * FROM students;
4. DCL – Data Control Language

Used to control user permissions.

Commands:

GRANT
REVOKE

Example:

GRANT SELECT ON students TO user1;
5. TCL – Transaction Control Language

Used to manage transactions.

Commands:

COMMIT
ROLLBACK
SAVEPOINT

Easy way to remember:

Sub-language	Purpose
DDL	Structure
DML	Modify data
DQL	Retrieve data
DCL	Permissions
TCL	Transactions
